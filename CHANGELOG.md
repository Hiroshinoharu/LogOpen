# Changelog

Versioned changes are generated from commit subjects and published with each
[GitHub Release](https://github.com/Hiroshinoharu/LogOpen/releases).

## Unreleased

- Make live monitoring prominent in the header, status panel, window title, and
  tray; explain silent baselines and paused notifications, and add a banner test
  with Windows notification diagnostics and consistent application identity.
- Give the desktop a distinctive mint-and-ink identity, an illustrated welcome,
  a unified scan panel, and compact summaries that keep results prominent.
- Improve readability, dark/light colour contrast, keyboard focus, form labels,
  summary-button semantics, and enlarged-text layouts throughout the desktop UI.
- Add saved reading options with text sizes up to 200%, reduced motion, and
  keyboard shortcuts for reading preferences and problem search.
- Windows CI tests and packages branch pushes and pull requests.
- Successful default-branch pushes publish automatically versioned installers
  and ZIPs, with release notes and SHA256 checksums.
- Patch releases are the default; feature and breaking-change commit messages
  select minor and major releases.

See [release automation](docs/releases.md) for version rules and retry behavior.
