# Changelog

Versioned changes are generated from commit subjects and published with each
[GitHub Release](https://github.com/Hiroshinoharu/LogOpen/releases).

## Unreleased

- Windows CI tests and packages branch pushes and pull requests.
- Successful default-branch pushes publish automatically versioned installers
  and ZIPs, with release notes and SHA256 checksums.
- Patch releases are the default; feature and breaking-change commit messages
  select minor and major releases.

See [release automation](docs/releases.md) for version rules and retry behavior.
